# Finding a record

Start with the [edition directory](README.md#edition-directory). Individual profiles use names and documented contributions in their titles; the stable record ID identifies the entry across revisions.

On GitHub, use the repository search or **Go to file** to locate a company, person or institution. Within a directory page, the browser’s Find command searches names and contributions. Code search availability depends on GitHub’s sign-in requirements.

The [full JSON](data/ranking2027.en.json) contains 390 records. Each record preserves its sources as reference-ID and URL pairs. The [full CSV](data/ranking2027.en.csv) stores paired source references and URLs in the same order. The [source-reference index](data/source-references.en.json) contains 1,024 references, including repeated URLs where separately cited.

Use the edition, assessment date, record ID and source-reference ID when citing a claim. A country or cluster position is a qualitative comparison; the other five groups are contribution-based selections. Record IDs are not ranks. The public materials support repository search and machine parsing; external search-engine indexing and AI retrieval vary by service.
