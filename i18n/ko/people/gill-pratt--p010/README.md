# Gill Pratt

공동 로봇공학 테스트 프로그램 주도

`P010` · Ecosystem Builders 50

## 선정·평가 근거 · 영문 원문

Gill Pratt led DARPA's Robotics Challenge program, providing common disaster-response tasks and test conditions for competing robot teams.

## 근거 범위 · 영문 원문

DARPA identifies Pratt as program manager and describes human-supervised systems and degraded communications; participating teams contributed their hardware, software and algorithms.
