## 선정·평가 근거 · 영문 원문

BeingBeyond trains robot behavior from human video. Being-H0.5 reports tests on five robot platforms, and its repository provides an SO101 deployment procedure.

## 근거 범위 · 영문 원문

Author-reported research and repository documentation; video-derived pseudo-tactile signals and physical tactile measurements have different scopes.
