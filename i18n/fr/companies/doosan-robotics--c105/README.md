# Doosan Robotics

Fourniture d’une plateforme de recherche en manipulation

`C105` · Current 100

## Motifs de sélection et d’évaluation · original anglais

An external Royal IHC project team used Doosan's 1013 arm in a vision-guided welding prototype. Doosan supplied the manipulation platform; the team developed the vision, integration and welding application.

## Portée des éléments probants · original anglais

Smart Manufacturing & Robotics Delft project account published 2025-03-16, covering fall 2023: Doosan 1013, RealSense D415, OpenCV detection and TCP motion commands in a constrained welding prototype.
