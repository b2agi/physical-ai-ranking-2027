# France

Open robot-learning tools and manipulation models.

2027 edition · October 2026 assessment · text revision v1.1, 12 October 2026 · record `country:08` · rank 8.

## Assessment

France provides open robot-learning tools and develops general-purpose manipulation models alongside hardware integrations.

## Evidence scope

Warehouse implementations, robot-learning tools, manufacturing integration, financing and testing access. Joint French-US development retains shared attribution.

## Evidence behind the assessment
